# BioInformatics-Repo

## Project 1: Bulk RNA-Seq Analysis Pipeline (GSE150910)

### 📌 Attributions & Disclaimer
This repository contains a full computational transcriptomics workflow built as part of an educational learning path. 

* **Original Tutorial Source:** This pipeline was built following the step-by-step methodologies from the **"Intro to Bioinformatics 8: Reading and Processing RNA-seq Data"** curriculum by **Mike Saint-Antoine**.
* **Primary Dataset Reference:** The dataset utilized is the public human clinical lung matrix **GSE150910**, retrieved from the NCBI Gene Expression Omnibus (GEO).

*Note: All data cleansing mechanisms (such as missing-value adjustments), statistical modeling (Kolmogorov-Smirnov testing), and visualization architectures (Volcano Plots and Cluster Heatmaps) were implemented manually for skill development based on the referenced educational course.*
